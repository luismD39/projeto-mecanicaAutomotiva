# Prompt inicial para Claude Code

Leia integralmente `CLAUDE.md`, `PROJECT_SPEC.md`, `DATA_MODEL.md`, `API_SPEC.md`, `DEVELOPMENT_PLAN.md` e `TEST_PLAN.md`.

Você será o responsável técnico pelo desenvolvimento do AutoScan Pro neste repositório.

Antes de escrever código:
1. Inspecione os arquivos e pastas existentes.
2. Identifique o sistema operacional/ambiente e a versão de Python disponível, se possível.
3. Aponte conflitos ou lacunas reais entre os documentos.
4. Apresente um plano curto para a Fase 1, sem tentar implementar o projeto inteiro de uma vez.

Depois, implemente somente a Fase 1 de `DEVELOPMENT_PLAN.md`: fundação Flask, configuração SQLite, endpoint `/api/health`, dependências e README inicial. Execute os testes ou verificações pertinentes.

Regras:
- Não crie uma interface falsa ou botões sem funcionalidade.
- Não afirme que existe conexão OBD-II real.
- Mantenha o produto em português do Brasil.
- Priorize código simples, modular, testável e apropriado para um projeto acadêmico.
- Não avance para a próxima fase sem apresentar o resultado e as pendências da fase atual.
- Não apague nem substitua arquivos existentes sem inspecioná-los.

Ao concluir, informe:
- o que foi implementado;
- arquivos criados/alterados;
- comandos para executar;
- testes executados e seus resultados;
- limitações ou decisões que precisam da minha aprovação.
